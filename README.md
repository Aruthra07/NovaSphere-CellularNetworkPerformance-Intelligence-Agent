# 🚀 NovaSphere — Cellular Network Performance Intelligence Agent

> **An evidence-driven AI-powered cellular network performance intelligence project built with Amazon Quick and Generative AI.**

NovaSphere transforms cellular network performance data into structured, verifiable intelligence through **full-dataset analysis, visualization, research, independent verification, reconciliation, and an AI-powered analysis agent**.

The project was developed as part of the **Udacity Nanodegree — Future AWS Agentic AI Business Professional** program.

---

## 🌐 Project Overview

**NovaSphere** is designed to analyze cellular network performance across different network technologies, localities, signal-quality measures, and time periods.

The project follows an evidence-first approach:

**Dataset → Verification → Analysis → Visualization → Research → Independent Validation → Reconciliation → AI Agent → Decision Intelligence**

Rather than relying on isolated observations or assumptions, the workflow emphasizes reproducible analysis and traceable evidence.

---

## 🎯 Project Objective

The primary objective is to investigate cellular network performance patterns and transform the available network data into actionable market and operational intelligence.

The analysis focuses on areas including:

- Cellular network performance
- Throughput
- Latency
- Network technology
- Locality-level performance
- Signal quality
- Signal correlation
- SDR measurements
- Performance trends over time
- 5G and locality relationships
- AI-assisted network intelligence

The project maintains clear analytical boundaries and distinguishes **observed data signals** from interpretation and strategic implications.

## 🔬 Analytical Workflow

### 1. Dataset Verification

The dataset was first uploaded and validated in Amazon Quick.

The verification workflow established the data foundation before proceeding to visualization and intelligence generation.

### 2. Network Performance Analysis

The project investigates network performance through multiple analytical views, including:

- Network-performance comparisons
- Throughput by network
- Throughput distribution
- Latency distribution
- Network performance over time
- Locality/network relationships

### 3. Signal Analysis

Signal-related analysis was performed to examine:

- Signal performance
- Signal correlations
- Signal quality
- SDR measurements
- Related network-performance relationships

### 4. Independent Verification

Important findings were subjected to additional verification steps to reduce the risk of relying on a single analytical output.

### 5. Final Reconciliation

The results were reconciled across the different verification stages before being incorporated into the final intelligence outputs.
